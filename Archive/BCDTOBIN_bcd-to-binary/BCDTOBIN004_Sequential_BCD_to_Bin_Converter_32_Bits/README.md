# Sequential BCD to Bin Converter (32 Bits)
<img alt="32_bits.png" src="images/32_bits.png?raw=1" height="300px">

**Authors:** *Flyingdean, aminotreal*

**Endorsed by:** *Mixel*

**Tags:** *Tested & Functional*

**Original post:** [View on Discord](https://discord.com/channels/1361854816837435433/1513197767487525105)

Converts a sequence of BCD digits into a 32-bit binary integer.
## Input
BCD digit, Shift, Clear
## Output
32b integer
## Notes
Based on Aminotreal's 16b stackable CCA. Can be upscaled and downscaled for any number of bits.

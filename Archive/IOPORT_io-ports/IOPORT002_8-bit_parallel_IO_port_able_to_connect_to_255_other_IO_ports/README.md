# 8-bit parallel I/O port able to connect to 255 other I/O ports

An 8-bit IO port that can send data at a rate of 1-Byte per 40 ticks, has an address on a universal bus connected to other 255 ports, and can store a byte in a buffer until cleared. It can also receive data sent on the universal bus.
## Speed
1-Byte per 40 ticks
## Notes
Has an address on a universal bus connected to other 255 ports; can store the byte in a buffer until cleared; can receive data sent on the universal bus.

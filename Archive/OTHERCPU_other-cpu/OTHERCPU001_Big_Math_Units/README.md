Performs one of the selected operations: Multiplication, Division, Square, Square Root, Modulo
## Input
Numbers 8b A and 8b B, Start calculating, Multiply, Divide, Modulo, Square, Square Root
## Output
8b value, Finished calculating
## Speed
Division and Modulo 112rt, Multiplication and Square 76rt, Square root 127rt
## Notes
Make sure only one operation is selected

An 8-bit carry-cancel adder with carry in and carry out, where both are ready at 3 ticks and are synced; each bit reads both carry lines directly. It is based on ideas learned from unnecessarymb's 8-bit Carry Cancel Adder, including sharing one dust for the xor and copy comparators carrying the kill line to the sums, and it uses an own layout designed with Claude (AI). A first block of a 32-bit adder is also in progress.
## Speed
3 ticks
## Notes
Ideas learned from unnecessarymb's 8-bit Carry Cancel Adder: a bit's A and B share one dust for the xor, and copy comparators carry the kill line to the sums. Our own layout, designed with Claude (AI). First block of a 32-bit adder in progress.

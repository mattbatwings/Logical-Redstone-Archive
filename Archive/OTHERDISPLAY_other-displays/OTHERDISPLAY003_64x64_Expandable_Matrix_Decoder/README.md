Description
An XY decoder that plots a pixel on a grid. Great for a pixel display. Infinitely expandable!
## Input
6b X, 6b Y
## Output
plotted pixel
## Speed
40 ticks (20 redstone ticks) for farthest pixel.
## Considerations
- not meant to be fast, just small and infinitely expandable.
- only expandable when binary decoders are adjusted for bigger sizes!

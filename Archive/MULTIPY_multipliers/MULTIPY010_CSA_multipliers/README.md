A collection of three multipliers for multiplying 8/16/32-bit numbers. It uses a looping Carry Save Adder (CSA) design shown in Bennyscubes video. The Carry Save Adders have CCAs attached to them, with the CCA design by Amino. The device runs on a 3rt clock cycle. It also functions on Bedrock by turning the glass blocks (of the CCAs) into upper half slabs.
## Input
Two 8 / 16 / 32 bit numbers
## Output
16 / 32 / 64 bit Multiplication result
## Speed
Runs on a 3rt clock cycle
## Notes
On Bedrock, the glass blocks of the CCAs have to be turned into upper half slabs

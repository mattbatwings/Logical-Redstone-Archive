A device that takes in two 32-bit numbers A and B and returns their 64-bit product. It uses the looping CSA design from Bennyscubes video and runs on a 3t loop.
## Input
Two 32-bit numbers A and B.
## Output
A 64-bit product.
## Speed
Runs on a 3t loop.
## Notes
Uses the looping CSA design from Bennyscubes video.

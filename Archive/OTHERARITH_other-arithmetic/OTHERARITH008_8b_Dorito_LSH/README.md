A barrel shifter based on the dorito design that is able to perform a left shift in 2 ticks.
## Input
8b value (1ss min), 3b shift value (15ss from lever)
## Output
8b left shifted value
## Speed
Input value 2t latency, Shift value 3t latency
## Notes
This design is inspired off other designs, the original authors of which are unknown. The levers are also missing on the input values. The lamps behind the targets are the output, the rest are input values I think you can figure it out ;)
